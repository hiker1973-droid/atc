Setup needs operator rights: you can look, but not change anything.

Your squadron

Your squadron's name and logo go on the dashboard, these pages and the browser tab. You can change them later in Settings.

Voice services

The OpenAI key is required: it is how Readback understands what pilots say. Readback speaks with the free Windows voices to start with; turn on OpenAI's natural voices in Settings, and an ElevenLabs key adds premium voices. Keys stay on this PC.

DCS server

Readback joins your DCS-SRS server as radio stations and reads the air picture from Tacview's real-time telemetry. Install Readback on the PC that runs the SRS server: SRS only takes Readback's transmissions from the same PC, so the server is localhost and its port (5002 unless you changed it).

Theatre

Pick the map your server flies, then untick anything you don't want on the radio. You can change all of this later under Settings → Roles.

Test call

Tune an SRS radio (in DCS or the SRS client's overlay) to the frequency below, then send. Readback speaks one short radio check: if you hear it, keys, voice and SRS all work.

Ready

That's it. Start the theatre now, or later from the dashboard.
