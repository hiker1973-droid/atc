# SkyEye ATC 0.1.0

First release.

- Setup wizard: squadron name and logo, OpenAI / ElevenLabs keys, SRS server, theatre (standard start files), test call.
- Settings: keys, connection, field frequencies, and every station's frequency, name, voice, speed and on/off.
- Free Windows voices by default; OpenAI voices as an upgrade; ElevenLabs with its key.
- 14-day trial; licence keys in Settings.
- Updates: the dashboard offers new versions.
