# Readback ATC 0.3.5

**Marshal and the carrier**
- Marshal calls "turning into wind" with the recovery window in minutes at Turn Into Wind start, then gives the BRC to all aircraft a few minutes later once the ship's heading settles.
- Marshal and Deckboss answer "requesting BRC", and no longer say "continue inbound" on DME acknowledgements.
- Case III: the reply adds "expect the Case Three CV-1 approach". Stale stack entries expire so the push time is no longer inflated.
- Marshal can find a player whose Tacview pilot name is stale.

**Paddles (LSO)**

- Passes are attributed correctly when Tacview's pilot name is stale, and a bolter before a reassigned trap stays with the same pilot.
