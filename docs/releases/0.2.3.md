# Readback ATC 0.2.3

- Reports: a new "Report contents" checklist chooses what goes in an After Action Report, the existing pages and seven new ones:
  - Comms score for each aircraft.
  - A page per pilot.
  - Currency.
  - Weapon effectiveness.
  - Losses.
  - Carrier recovery.
  - Tankers.
- With Claude's write-up unticked, a report is saved without needing a Claude key.
- Reports now include Command, Marshal and tanker radio calls, not just the towers'.
- The User Manual explains each report option.
