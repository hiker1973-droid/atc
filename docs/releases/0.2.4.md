# Readback ATC 0.2.4

- Settings > Roles is now three groups: ATIS, Towers and Other stations.
  - Each station has a Remove button, and each group an Add list that brings a removed one back or starts a new one.
  - ATIS: rename a field's broadcast, change its voice, take it off the air, or add an ATIS at a field that has none, on your own frequency.
  - Towers: change the name a tower calls itself on the radio, e.g. "Senaki Approach".
  - Tankers: every tanker is listed, and you can add new ones with their own callsign, frequency, altitude, speed, basket or boom, and voice.
  - A frequency already in use in the theatre is refused.
- Help > Report a problem: describe what went wrong and Readback makes one zip of its logs and settings, with every key removed, to post in #bug-reports on our Discord.
- Reports: the Comms score counts the AWACS's answers, so calls to Darkstar are no longer marked unanswered.
- Reports: a PC that watches several servers can read the radio logs from the server that flew the session.
