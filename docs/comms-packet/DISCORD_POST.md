**Hitman's 9-line readback is simpler: he only checks the grid** 🎯

Same three blocks as before, but now one line matters. Read back the **location** (line 6). Everything else, a "copy" is fine.
```
Lines 1-3   IP, heading, distance          -> "copy"
Lines 4-6   elevation, target, location    -> read back the grid
Lines 7-9   mark, friendlies, egress       -> "copy"
Hitman: "Confirmed. Report IP inbound."
```
• The grid is two letters then ten digits, no zone: *"Golf Juliet, three one eight two seven, seven zero four five seven"*. Read it back the same way
• Grid wrong? He says line 6 again. Wrong twice: he says it once more, *"continue"*, and gives you lines 7-9
• Missed it? *"Say again"* repeats the block. *"Say again location"* (or *"say again line 6"*) repeats the grid
• Don't say "Hitman" halfway through your readback; lead with it or leave it out
• Everything after "confirmed" (IP inbound, in, cleared hot, off, BDA) is unchanged

The kneeboard card still shows the full grid with the zone (37T). Works for every target, Black Sea and the TIC mission.
